================================================================================
  AMAPRO ATTENDANCE SYSTEM — MOBILE APP & MODAL SERVERLESS SETUP GUIDE
================================================================================

All commands assume you are in the project root:
  cd /h3/anas/AMAPro

===============================================================================
  1. MODAL SERVERLESS BACKEND DEPLOYMENT
===============================================================================

# Step 1: Deploy to Modal (NVIDIA T4 GPU)
modal deploy modal_deploy.py

# Step 2: Test locally with live reload
modal serve modal_deploy.py


===============================================================================
  2. ANDROID MOBILE & TABLET APP BUILD
===============================================================================

cd android_clientv7

# Build Debug APK
./gradlew assembleDebug

# Output APK file location:
# android_clientv7/app/build/outputs/apk/debug/AMAPro_Attendance.apk


===============================================================================
  3. BATCH ENROLLMENT ON MODAL (OPTIONAL)
===============================================================================

# Place photos in Employees_Photo/ (format: "Firstname Lastname EMP_ID.jpg")
# Run batch enrollment task on Modal T4 GPU:
modal run modal_deploy.py::enroll_all_employees
